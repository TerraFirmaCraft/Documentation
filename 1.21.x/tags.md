# Tags

This page details all the tags that TFC adds, and uses for various functions. These have been separated out into [Block Tags](#block-tags), [Fluid Tags](#fluid-tags), [Item Tags](#item-tags), [Entity Tags](#entity-tags), and a separate page for [Worldgen Tags](../worldgen/tags).
